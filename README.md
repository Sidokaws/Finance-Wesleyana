# Finance Wesleyana

Painel financeiro pessoal e do casal, feito para registrar movimentos de forma simples e transformar lançamentos em uma visão clara do mês.

## V1

- Visões separadas: Sidmar, Ana e Nós
- Receitas, despesas e reservas
- Saldos informados manualmente
- Dinheiro livre, comprometido e guardado
- Lançamento rápido por texto
- Categorias de gastos
- Gastos recorrentes
- Metas financeiras
- Histórico recente
- Próximos compromissos
- Persistência local via `localStorage`
- Layout responsivo para desktop e celular

## Segurança

O projeto não deve armazenar senhas bancárias, CVV, tokens, números completos de cartão ou credenciais de banco. Nesta fase, os dados são de gestão e são preenchidos manualmente pelo usuário.
